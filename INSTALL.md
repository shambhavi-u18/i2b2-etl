# i2b2-ETL Installation Guide
This document is a guide to deploy the i2b2-ETL environment on an AWS EC2 instance, including modifications required to build the Docker image.

## EC2 Configuration
Create an EC2 instance with the following configurations 
- **AMI:** Ubuntu 24.04
- **Instance Type:** t3a.medium
- **Volume:** 30 GiB
- **Update the Security Group to include:** 
    1. custom TCP, 8080, Anywhere (0.0.0.0/0) --> i2b2 web interface 
    2. HTTP, 80, Anywhere (0.0.0.0/0) --> i2b2-etl web interface
    3. custom TCP, 5000, Anywhere (0.0.0.0/0) --> Swagger API 

## SSH Setup 
Update the downloaded key configuration:
```bash
chmod 400 <key>
```

Connect to the EC2 instance:
```bash
ssh -i <key> ubuntu@<public-ip>
```

## Install Docker 
Once connected to your EC2 instance, download Docker on it. 

Install Docker on Ubuntu following the Docker documentation: https://docs.docker.com/engine/install/ubuntu/

Verify Docker Installation:
```bash
docker --version
docker compose version
```

## Clone Required Repositories
Before following the steps in each repository, note the modifications/reminders below 

Clone the i2b2 repository: (follow steps in each repository) 
```bash
git clone https://github.com/i2b2/i2b2-docker
```

Clone the i2b2-ETL repository: (follow steps in each repository) 
```bash
git clone https://github.com/i2b2/i2b2-etl
```

## Modifications/Reminders 
Before the build command do the following fixes in the Dockerfile i2b2-ETL:
1. Change the Ubuntu type to 24.04 
2. Near line 50, add the missing backslash (`\`) characters to the affected `RUN` commands. And at the end of those lines remove trailing `&&` operators. 
3. Near lines 50 instead of using the system pip replace the default pip invocation with:

```dockerfile
RUN /usr/src/app/.venv/bin/pip install ...
```

4. After following the repository instructions to build the image, update the ETL tag. Note to update the tag, the file path is `~/i2b2-docker/pg/i2b2-etl/deployment/pg/.env` 

## Accessing the ETL Container 
Follow the steps on the i2b2-etl repository to build your container, and access the test case. Note, please make the following changes, to ensure the tests run smoothly: 
1. Change the import path in `tests/ML/test_ml_mimic_hf.py`
- Original:
    ```python
    from i2b2_cdi.tests.ML.test_helper import create_patient_set
    ```

- Modified:
    ```python
    from tests.ML.test_helper import create_patient_set
    ```

2. Comment out the following line in `tests/ML/test_ml_pima.py`
    ```python
    !curl "http://i2b2-etl:5000/etl/concepts"
    ```

3. The test directory in the current repository structure, use this to run tests: 
    ```bash
    python -m unittest discover -s tests/
    ```
